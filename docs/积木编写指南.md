# CI Blocks 积木编写指南

> 5 分钟写你的第一个积木。

---

## 这是什么

CI Blocks 的积木是**插件**。每个积木：

- 描述一个 CI 步骤（或一组步骤）
- 声明它的输入字段
- 把输入转成 IR（中间表示）
- 由 emitter 生成最终 YAML

**你写积木，编辑器自动渲染表单，CIB 自动生成脚本。**

---

## 快速开始

### 1. 装 SDK

```bash
pnpm add @cib/block-sdk
```

### 2. 写第一个积木

新建 `src/hello.ts`：

```ts
import { 定义积木, type IRNode } from '@cib/block-sdk';

export const 你好积木 = 定义积木({
  id: 'my/hello',
  keyword: '你好',
  version: '0.1.0',
  category: '基础',
  meta: {
    icon: '👋',
    author: '你的名字',
    license: 'MIT',
    描述: '打印一句问候',
    tags: ['hello'],
  },
  schema: [
    {
      键: '名字',
      类型: '文本',
      必填: true,
      默认: '世界',
      说明: '要问候的对象',
    },
  ],
  生成IR: (输入): IRNode[] => [
    {
      kind: '作业',
      id: 'hello',
      keyword: '你好',
      运行环境: 'ubuntu-latest',
      步骤: [
        {
          kind: '步骤',
          keyword: '打印',
          name: `问候 ${输入.名字}`,
          run: `echo "你好，${输入.名字}！"`,
        },
      ],
    },
  ],
});
```

### 3. 在编辑器里用

```ts
import { 你好积木 } from './hello';
设置积木箱([...内置积木, 你好积木]);
```

**或**等编辑器支持"加载本地积木"后，直接指定路径。

## 积木接口

```ts
interface CIBBlock<输入 = Record<string, unknown>> {
  id: string;                    // 全局唯一，如 cib/time-gate
  keyword: string;               // 显示名，如 时间铡刀
  aliases?: string[];            // 别名，命令面板可搜
  version: string;               // 语义化版本
  category: 积木分类;             // 分类
  meta: {
    icon?: string;               // emoji
    author: string;
    license: string;
    描述: string;
    tags: string[];
    permissions?: string[];      // 声明所需权限（未来）
  };
  schema: 字段描述[];             // 输入字段
  生成IR: (输入, 上下文) => IRNode[];
  还原输入?: (节点) => 输入 | null; // 可选，YAML 反解析
  校验?: (输入) => 诊断[];         // 可选，校验
}
```

## 分类

```ts
type 积木分类 =
  | '基础'    // 触发、条件、判定
  | '门禁'    // 拦截、保护
  | '构建'    // 编译、打包
  | '校验'    // 测试、检查
  | '科研'    // 数据、复现
  | '项目'    // 契约、接口
  | '审计'    // 日志、记录
  | '环境'    // 缓存、变量
  | '部署';   // 发布、推送
```

**分类决定积木在工具箱里的分组和颜色。**

## 字段类型

| 类型 | Blockly 渲染 | 说明 |
|---|---|---|
| `文本` | 文本输入框 | 单行字符串 |
| `时间` | 文本输入框 | ISO8601 时间字符串 |
| `日期时间` | 6 个下拉框（年月日时分秒） | 自动拼成 ISO8601 |
| `枚举` | 下拉框 | 必须提供 `选项` |
| `布尔` | 复选框 | |
| `数字` | 数字输入框 | |
| `路径列表` | 文本输入框 | 逗号分隔 |

**示例**：

```ts
schema: [
  { 键: '命令', 类型: '文本', 必填: true, 默认: 'npm test' },
  { 键: '模式', 类型: '枚举', 选项: ['快', '慢'], 默认: '快' },
  { 键: '启用', 类型: '布尔', 默认: true },
  { 键: '超时', 类型: '数字', 默认: 10 },
  { 键: '截止', 类型: '日期时间', 必填: true },
]
```

## IR 类型

积木产出 **IR 节点**。**emitter 把 IR 转成 YAML。**

### `IR作业`（最常用）

代表一个 GitHub Actions job。

```ts
{
  kind: '作业',
  id: 'build',                          // job id
  keyword: '自动编译',
  运行环境: 'ubuntu-latest',
  步骤: [ ...IR步骤 ],
  needs?: ['gates'],                    // 可选，依赖
  environment?: { name: 'prod' },       // 可选
}
```

### `IR步骤`

代表 job 里的一个 step。

```ts
{
  kind: '步骤',
  keyword: '检出代码',
  name: '检出代码',                      // step 名
  uses?: 'actions/checkout@v4',         // 用 action
  run?: 'npm test',                     // 或跑命令
  with?: { 'node-version': '22' },      // action 参数
  env?: { NODE_ENV: 'production' },     // 环境变量
  'working-directory'?: '.',            // 工作目录
  if?: 'always()',                      // 条件
  timeout?: 10,                         // 超时分钟
  'continue-on-error'?: false,
}
```

### `IR门禁`

代表一个拦截规则（**会合并到 `gates` job**）。

```ts
{
  kind: '门禁',
  keyword: '时间铡刀',
  blockId: 'cib/time-gate',
  拦截时机: '提交时',
  参数: { 基准时间: '...', 模式: '超时封仓' },
}
```

**门禁型积木的产出会被合并到同一个 `gates` job**，**每个门禁是一个 step**。

### 其他 IR

- `IR触发器`：`on:` 事件
- `IR过滤`：事件过滤（branches / paths）
- `IR判定`：根据 job 结果分支

---

## 判断用哪种 IR

| 你的积木干什么 | 用 |
|---|---|
| 加一个 job | `IR作业` |
| 加一个 step 到某 job | 放进 `IR作业.步骤` |
| 拦截提交 / 合并 | `IR门禁` |
| 改触发器 | `IR触发器` |
| 改触发器过滤 | `IR过滤` |
| 根据结果分支 | `IR判定` |

## 完整示例：Slack 通知

```ts
import { 定义积木, type IRNode } from '@cib/block-sdk';

export const Slack通知 = 定义积木({
  id: 'my/slack-notify',
  keyword: 'Slack 通知',
  aliases: ['slack', '通知'],
  version: '0.1.0',
  category: '审计',
  meta: {
    icon: '💬',
    author: '张三',
    license: 'MIT',
    描述: '把 CI 结果发到 Slack',
    tags: ['slack', '通知'],
  },
  schema: [
    {
      键: 'Webhook Secret 名',
      类型: '文本',
      必填: true,
      默认: 'SLACK_WEBHOOK',
      说明: '存到 GitHub Secrets 的名字',
    },
    {
      键: '消息',
      类型: '文本',
      默认: 'CI 完成：${{ job.status }}',
    },
  ],
  生成IR: (输入): IRNode[] => [
    {
      kind: '作业',
      id: 'slack_notify',
      keyword: 'Slack 通知',
      运行环境: 'ubuntu-latest',
      步骤: [
        {
          kind: '步骤',
          keyword: '发送',
          name: '发送 Slack 消息',
          uses: '8398a7/action-slack@v3',
          with: {
            status: '${{ job.status }}',
            text: 输入.消息,
            webhook_url: `\${{ secrets.${输入['Webhook Secret 名']} }}`,
          },
        },
      ],
    },
  ],
  校验: (输入) => {
    const 问题 = [];
    if (!输入['Webhook Secret 名']?.trim()) {
      问题.push({ 级别: '错误', 消息: 'Webhook Secret 名不能为空' });
    }
    return 问题;
  },
});
```

---

## 校验函数

**可选**。**返回诊断数组**。

```ts
校验: (输入) => {
  const 问题 = [];
  if (!输入.必填项?.trim()) {
    问题.push({ 级别: '错误', 消息: '必填项不能为空' });
  }
  const 数字 = parseInt(输入.阈值 ?? '', 10);
  if (Number.isNaN(数字) || 数字 < 0) {
    问题.push({ 级别: '错误', 消息: '阈值必须是非负整数' });
  }
  if (输入.某字段 === '某值') {
    问题.push({ 级别: '警告', 消息: '某值可能不是你要的' });
  }
  return 问题;
}
```

**级别**：`'错误'` / `'警告'`。

## 命名规范

| 项 | 规则 |
|---|---|
| **`id`** | 小写字母 + 短横线，带命名空间：`yourname/block-name` |
| **`keyword`** | 中文（或英文），面向用户 |
| **`category`** | 从 9 个分类里选 |
| **字段 `键`** | 中文，面向用户 |
| **字段 `说明`** | 中文，写清用途 |

**官方积木的 `id` 用 `cib/` 前缀**，**社区的用自己的前缀**。

## 最佳实践

### 1. 默认值要合理

**用户拖出来就能用**，不用填一堆。

```ts
{ 键: '版本', 类型: '文本', 默认: '22' }
```

### 2. `说明` 要具体

```ts
// ❌ 差
{ 键: '命令', 说明: '命令' }

// ✅ 好
{ 键: '命令', 说明: '如 npm test、./gradlew test、pytest' }
```

### 3. 敏感信息走 Secrets

**不要在 YAML 里写 token**。

```ts
webhook_url: `\${{ secrets.${输入['Webhook Secret 名']} }}`
```

### 4. 支持"仅告警"模式

**给用户选择权**：

```ts
{ 键: '失败动作', 类型: '枚举', 选项: ['拒绝', '仅告警'], 默认: '拒绝' }
```

### 5. 加 `if-no-files-found: ignore`

**上传 artifact 时**，**避免路径不存在就失败**。

```ts
with: {
  name: 'report',
  path: 'build/reports/',
  'if-no-files-found': 'ignore',
}
```

## 常见问题

### Q：积木能嵌套吗

**能**。`行为条件` / `工作流判定条件` 用了 Blockly 的 `appendStatementInput`，**其他积木可以嵌进去**。

**你的积木默认是"普通块"**，**可接在链上**。

### Q：能读其他 job 的产物吗

**能**。用 `actions/download-artifact@v4`，**但要先有上传**。

### Q：能改 `on:` 吗

**不能直接改**。**用 `IR触发器` 和 `IR过滤`**。

### Q：能访问 Secrets 吗

**生成的 YAML 里用 `${{ secrets.XXX }}`**，**运行时会注入**。**你的积木代码里看不到 Secrets 的值**。

### Q：怎么调试

1. `pnpm test` 跑单测
2. 编辑器里拖出来，看右侧 YAML
3. 生成的 YAML 扔进 GitHub 仓库跑
