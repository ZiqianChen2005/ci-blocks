# 示例模板

## 使用方法

1. 打开 CI Blocks 编辑器（`pnpm dev`）
2. 文件 → 从模板新建 → 选模板

## 模板列表

见 [`index.json`](./index.json)。

## 贡献模板

1. 在编辑器里搭好积木
2. 文件 → 保存
3. 保存到 `examples/` 目录
4. 在 `index.json` 里加一条
5. 提 PR

## `.cib` 格式

```json
{
  "格式": "cib",
  "版本": "0.1.0",
  "保存时间": "2026-09-26T...",
  "语言": "zh-CN",
  "工作流名称": "模板名",
  "工作区": { ... Blockly 序列化 ... }
}
```
